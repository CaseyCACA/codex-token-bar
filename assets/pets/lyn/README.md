# LYN Codex Pet

刘宇宁 Q 版风格的 Codex 桌面宠物资产，作为 Token Bar 的配套宠物资源提供。

- `spritesheet.webp`：Codex-compatible v2，8 列 × 11 行，RGBA。
- `pet.json`：宠物 ID、显示名、描述和 v2 版本声明。
- `contact-sheet.png`：标准动作预览。
- `look-directions.png`：16 个视线方向预览。
- `validation.json`：发布前的确定性校验结果。

`validation.json` 中的 `ok: true` 表示这份 spritesheet 已通过结构与透明度检查。
