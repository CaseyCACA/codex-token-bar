# 安装说明（预览版准备中）

当前没有已验证的 Release。以下常规下载步骤供未来正式批准的预览包使用。

## 当前 GitHub Actions 测试候选

Owner 已允许将候选包保存在公开仓库的 GitHub Actions，保留 7 天。它不是私密文件，
不是正式 Release，也没有经过苹果公证或真实 Mac 安装验收。

打开维护者提供的精确 Actions run，在 Artifacts 中下载带有
`unnotarized-pending-mac-acceptance-<提交>-macos15-arm64-...` 的候选。
这是唯一的 canonical 候选：来源为该提交在 macos-15 runner 上构建的 Universal 应用，
不是把不同构建任务的安装包混在一起。网页下载通常需要登录 GitHub。

先解压 Actions 的外层 artifact ZIP；里面的 `Codex-Token-Bar-...zip` 才是应用包，
另有 `BUILD-INFO.txt` 和 `SHA256SUMS`。核对 BUILD-INFO 的提交、run 和测试状态，
再对内层应用 ZIP 执行下文 SHA-256 校验。外层 artifact 的 digest 与内层应用 ZIP
的 SHA-256 是两个不同值，不能混用。文件过期、来源不符或校验失败时不要安装。

## 未来获准预览版的下载步骤

1. 仅从本仓库 Releases 下载 `Codex-Token-Bar-<版本>-preview-universal-macos.zip`。
   GitHub 自动生成的 Source code ZIP 是源码，不是应用。
2. 需要 macOS 13+；Universal 包包含 Apple Silicon 和 Intel 两种架构。
   最低系统版本是构建目标，实际测试过的系统以该 Release 说明为准。
3. 解压，将 `Token Bar.app` 拖进“应用程序”，再打开。无需 Xcode 或编译。
4. 应用只出现在菜单栏，没有普通主窗口。点击菜单栏圆环打开面板。
5. 需要已安装并登录 Codex。当前仅自动查找：
   `/Applications/ChatGPT.app/Contents/Resources/codex`、
   `/Applications/Codex.app/Contents/Resources/codex`、
   `/opt/homebrew/bin/codex`、`/usr/local/bin/codex`。
   其他安装位置可能出现“找不到 Codex App Server”。

## 未公证预览版的安全提示

预览包仅采用 ad-hoc 签名，不能验证开发者身份，没有经过苹果公证。
macOS 可能阻止首次打开；这不是安装成功或安全性保证。
只有你确认来源可信并愿意承担测试风险时，才按 Apple 官方说明，在尝试打开后
进入“系统设置 → 隐私与安全”，核对应用名称后选择“仍要打开”。
组织管理的 Mac 可能禁止例外；此时应等待公证版或联系管理员。
若提示恶意软件、损坏或校验不符，停止安装并反馈，不要强行绕过。
本项目不要求关闭 Gatekeeper、SIP，也不要求执行递归删除 quarantine 的命令。

可选完整性校验：把 ZIP 与同一 Release 的 SHA256SUMS 放在同一目录，在终端运行
`shasum -a 256 -c SHA256SUMS`。哈希只能发现文件不一致，不能证明开发者身份或无恶意代码。

## 权限与故障

- 应用读取 `~/.codex/sessions`，并启动本机 Codex App Server 查询账户额度。
  “本地运行”不表示 Codex App Server 查询账户时绝不会联网。
- 宠物跟随功能使用窗口图像检测，可能受屏幕录制权限和系统版本影响。
  请先验证菜单栏监控，再单独测试浮标；无需为安装而预先授予完全磁盘访问权限。
- 首次无会话、未登录、Codex 更新或内部接口变化均可能导致无数据。
  `--` 或读取失败不等于额度为零。
- 升级：退出旧版，替换“应用程序”中的同名应用。卸载：退出后删除该应用；
  不要删除 Codex 会话目录。卸载应用不会自动清除其偏好设置。

## 首次测试：先确认能用，再确认浮标

以下仅供获准试用的候选包使用，不表示当前已有可下载版本。

- 记录安装包版本、macOS 版本和芯片类型（Apple Silicon 或 Intel）。
- 从浏览器下载获准的 ZIP 并核对 SHA-256；记录首次打开的实际系统提示。
  不要用构建机直接运行的结果代替下载测试，不要为测试降低系统安全设置。
- 打开后确认菜单栏出现图标，点击能展开面板；退出后图标消失，重新打开能恢复。
- 在已登录 Codex 的情况下，对照其主额度剩余比例和重置时间；记录差异，
  不要把“本任务 Token”当作账户扣费或剩余额度。
- 在没有可读取会话或无法获取额度时，确认显示“--”或失败提示，而不是误报零额度。
  不要为了测试删除会话、退出重要工作或公开账户信息。
- 最后再检查宠物浮标显示、隐藏、拖动和跟随；若出现权限请求，可拒绝并记录结果。
  菜单栏功能和浮标功能分别记录，不要把部分通过写成全部通过。
- 记录替换升级、退出和重开是否正常。遇到系统恶意软件提示、损坏提示或哈希不符，
  立即停止，不要强行绕过。

## 如何反馈问题

可在本仓库 [Issues](https://github.com/CaseyCACA/codex-token-bar/issues) 提交反馈；
提交前先检查是否已有相同问题。建议包含：

- 安装包版本及下载来源；macOS 版本、芯片类型、Codex 版本。
- 出问题的步骤、预期结果、实际结果，以及能否重复发生。
- 菜单栏额度、浮标、首次打开或升级中的哪一项有问题。
- 已脱敏的错误文字或局部截图。

不要上传 Codex 原始会话日志、对话内容、完整账户信息、访问令牌或认证文件。
日志可能包含提示词、文件路径和业务数据；默认只提供上述最小信息。
截图请遮住邮箱、工作内容及其他私人信息。作者若需要额外诊断信息，
应先说明所需字段，再由你决定是否提供；不要直接把整个用户目录打包上传。
